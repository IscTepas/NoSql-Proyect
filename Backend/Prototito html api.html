FIFA World Cup 2026 — Documentación API

API REST para la gestión completa del Mundial FIFA 2026. Recursos: equipos, partidos, estadios y grupos.

Base URL http://localhost:3000

Equipos

Gestión de los 48 equipos participantes del Mundial. Referenciados por partidos y grupos.

GET
/api/equipos
Obtener todos los equipos. Filtrable por grupo.
▼
Parámetros de consulta (Query)
ParámetroTipoRequeridoDescripción
grupo string opcional Filtrar por letra de grupo. Ej: ?grupo=A
JSON recibido
{
  "ok": true,
  "total": 3,
  "data": [
    {
      "_id": "664a1b...",
      "nombre": "México",
      "bandera": "🇲🇽",
      "fifaCode": "MEX",
      "iso2": "MX",
      "grupo": "A"
    }
  ]
}
Respuestas
200 Lista de equipos obtenida correctamente
500 Error interno del servidor
GET
/api/equipos/:id
Obtener un equipo específico por su ID de MongoDB.
▼
Parámetros de ruta
ParámetroTipoRequeridoDescripción
id string requerido ID de MongoDB del equipo
JSON recibido
{
  "ok": true,
  "data": {
    "_id": "664a1b...",
    "nombre": "México",
    "bandera": "🇲🇽",
    "fifaCode": "MEX",
    "iso2": "MX",
    "grupo": "A"
  }
}
Respuestas
200 Equipo encontrado
404 Equipo no encontrado
500 Error interno del servidor
POST
/api/equipos
Crear un nuevo equipo en la base de datos.
▼
JSON enviado
CampoTipoRequeridoDescripción
nombre*stringrequeridoNombre del país
fifaCode*stringrequeridoCódigo FIFA de 3 letras. Ej: MEX
iso2*stringrequeridoCódigo ISO de 2 letras. Ej: MX
grupo*stringrequeridoLetra del grupo. Ej: A
banderastringopcionalEmoji de bandera. Ej: 🇲🇽
Ejemplo de JSON enviado
{
  "nombre": "México",

Partidos

Gestión de todos los partidos del torneo. Soporta fases de grupos y eliminatoria. Los campos de equipo regresan el documento completo (populate).

GET
/api/partidos
Obtener todos los partidos. Filtrable por fase y estado.
▼
Parámetros de consulta (Query)
ParámetroTipoRequeridoDescripción
fasestringopcionalgrupos · dieciseisavos · octavos · cuartos · semifinal · tercer_lugar · final
estadostringopcionalprogramado · en_curso · finalizado · suspendido
JSON recibido
{
  "ok": true,
  "total": 1,
  "data": [
    {
      "_id": "664b2c...",
      "equipoLocal": { "nombre": "México", "bandera": "🇲🇽", "fifaCode": "MEX" },
      "equipoVisitante": { "nombre": "Canadá", "bandera": "🇨🇦", "fifaCode": "CAN" },
      "marcadorLocal": 2,
      "marcadorVisitante": 0,
      "fase": "grupos",
      "estado": "finalizado",
      "fecha": "2026-06-11T20:00:00.000Z",
      "estadio": { "nombre": "Estadio Azteca", "ciudad": "Ciudad de México" }
    }
  ]
}
Respuestas
200 Lista de partidos obtenida correctamente
500 Error interno del servidor
POST
/api/partidos
Crear un nuevo partido. Los equipos se asignan por ID de MongoDB.
▼
Campos del JSON enviado
CampoTipoRequeridoDescripción
fechaDaterequeridoFecha y hora del partido en formato ISO 8601
estadioObjectIdrequeridoID del estadio donde se jugará
equipoLocalObjectIdopcionalID del equipo local
equipoVisitanteObjectIdopcionalID del equipo visitante
fasestringopcionalgrupos · octavos · cuartos · semifinal · final (default: grupos)
etiquetaLocalstringopcionalEtiqueta cuando el equipo aún no está definido. Ej: "1A"
jornadanumberopcionalNúmero de jornada en fase de grupos
Ejemplo de JSON enviado
{
  "equipoLocal": "664a1b...",
  "equipoVisitante": "664a2c...",
  "fecha": "2026-06-11T20:00:00.000Z",
  "estadio": "664c3d...",
  "fase": "grupos",
  "jornada": 1
}
JSON recibido
{
  "ok": true,
  "mensaje": "Partido creado",
  "data": { ... partido insertado ... }
}
Respuestas
201 Partido creado correctamente
400 Datos inválidos o faltantes
PUT
/api/partidos/:id
Actualizar un partido. Usado principalmente para registrar marcador y cambiar estado.
▼
Ejemplo de JSON enviado — actualizar marcador

}
JSON recibido
{
  "ok": true,
  "mensaje": "Partido actualizado",
  "data": { ... partido actualizado ... }
}
Respuestas
200 Partido actualizado correctamente
404 Partido no encontrado
