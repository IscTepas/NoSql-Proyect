FIFA World Cup 2026 — Documentación API

API REST para la gestión completa del Mundial FIFA 2026. Recursos: equipos, jugadores, partidos, estadios y grupos.

Base URL http://localhost:3000

Equipos

Gestión de los 48 equipos participantes del Mundial. Referenciados por partidos, grupos y jugadores.

GET
/api/equipos
Obtener todos los equipos.
▼
JSON recibido
{
  "ok": true,
  "total": 48,
  "data": [
    {
      "_id": "664a1b...",
      "nombre": "México",
      "bandera": "🇲🇽",
      "fifaCode": "MEX",
      "iso2": "MX",
      "grupo": "A"
    }
  ]
}
Respuestas
200 Lista de equipos obtenida correctamente
500 Error interno del servidor
GET
/api/equipos/:id
Obtener un equipo específico por su ID de MongoDB.
▼
Parámetros de ruta
ParámetroTipoRequeridoDescripción
id string requerido ID de MongoDB del equipo
JSON recibido
{
  "ok": true,
  "data": {
    "_id": "664a1b...",
    "nombre": "México",
    "bandera": "🇲🇽",
    "fifaCode": "MEX",
    "iso2": "MX",
    "grupo": "A"
  }
}
Respuestas
200 Equipo encontrado
404 Equipo no encontrado
500 Error interno del servidor
POST
/api/equipos
Crear un nuevo equipo en la base de datos.
▼
Ejemplo de JSON enviado
{
  "nombre": "México",
  "bandera": "🇲🇽",
  "fifaCode": "MEX",
  "iso2": "MX",
  "grupo": "A"
}
JSON recibido
{
  "ok": true,
  "mensaje": "Equipo creado correctamente",
  "data": { ... equipo insertado ... }
}
Respuestas
201 Equipo creado correctamente
400 Datos inválidos o faltantes
PUT
/api/equipos/:id
Actualizar los datos de un equipo existente.
▼
Ejemplo de JSON enviado
{
  "grupo": "B",
  "bandera": "🇲🇽"
}
JSON recibido
{
  "ok": true,
  "mensaje": "Equipo actualizado correctamente",
  "data": { ... equipo actualizado ... }
}
Respuestas
200 Equipo actualizado correctamente
404 Equipo no encontrado
DELETE
/api/equipos/:id
Eliminar un equipo de la base de datos.
▼
JSON recibido
{
  "ok": true,
  "mensaje": "Equipo eliminado correctamente",
  "data": { ... equipo eliminado ... }

Jugadores

Gestión de las plantillas oficiales de futbolistas convocados por cada equipo.

GET
/api/jugadores
Obtener todos los jugadores. Filtrable por equipo.
▼
Parámetros de consulta (Query)
ParámetroTipoRequeridoDescripción
equipo string opcional ID de MongoDB del equipo para filtrar su plantilla. Ej: ?equipo=664a1b...
JSON recibido
{
  "ok": true,
  "total": 1,
  "data": [
    {
      "_id": "664e5f...",
      "nombre": "Edson Álvarez",
      "numero": 4,
      "posicion": "MF",
      "fechaNacimiento": "1997-10-24",
      "club": { "nombre": "West Ham", "pais": "ENG" },
      "fifaCodeEquipo": "MEX",
      "equipo": { "nombre": "México", "fifaCode": "MEX" }
    }
  ]
}
Respuestas
200 Lista de jugadores obtenida correctamente
GET
/api/jugadores/:id
Obtener un jugador por su ID de MongoDB.
▼
JSON recibido
{
  "ok": true,
  "data": {
    "_id": "664e5f...",
    "nombre": "Edson Álvarez",
    "numero": 4,
    "posicion": "MF",
    "equipo": { "nombre": "México" }
  }
}
Respuestas
200 Jugador encontrado
404 Jugador no encontrado
